# 🎬 Catálogo de Filmes

Aplicação em React que consome a API do TMDb para exibir um catálogo de filmes populares com detalhes dinâmicos, sistema de comentários e alternância entre temas escuro e claro.

---

## 🚀 Tecnologias utilizadas

- **React**
- **React Router DOM**
- **TMDb API**
- **CSS Modules**
- **LocalStorage**
- **Vercel**
